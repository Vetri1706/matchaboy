The console remains interactive. This pass confines the changes to the console sequence and its recorded Inspector handoff. The rest of the website and native app were kept in place.

What changed

  • Named front shell, screen assembly, controls, board and rear shell. Parts interpolate between explicit assembled and opened positions along one shared axis.
  • Presentation rotation and nested drag rotation have separate owners. Scroll, chapter copy and replay read one master progress value. Reverse scrolling retraces the arrangement.
  • Fixed exposure and studio lighting; distinct plastic, rubber controls, screen glass and coated board. A/B openings have inner walls and rims. Existing speaker cutouts, rear recesses, mounting posts and board components remain real geometry.
  • A reserved model viewport protects the copy. Small screens put the copy above the assembly. Static posters cover loading, opted-in still view, reduced motion and 3D failure.
  • Try the screen → Pause & open freezes the browser mini-game. Inspect a recorded moment opens the native Inspector example; it is a separate captured game, not a claimed transfer of live emulator state.

Verified

36 saved canvas frames: nine positions in both directions at 1672 × 940 and 375 × 667. Every sampled text box clears the model viewport (minimum 28.0 px desktop, 6.4 px mobile), and neither scene nor text crosses the chapter navigation. Maximum settled forward/reverse pose difference: 0.004339. Pixel-rounded scroll positions have a small tolerance; requested and observed progress are retained in the capture data.

Independent perspective projection passed 7,236 poses, including intermediate positions and pointer extremes. All tested part bounds stayed within 91% of the viewport. Shared-axis motion, pointer isolation, reverse convergence, replay interruption and reduced still poses passed.

Browser actions checked: keyboard entry into the screen, Escape returning focus to the play control, Tab/Enter activating Pause & open, the Inspector handoff focusing the next-frame button, Enter revealing frame 155 and its measured change, and the hero Download action reaching the visible download choices. The GitHub release API confirmed all three linked v0.1.0 ZIP assets. Package downloads and installations were not repeated.

Reduced-motion and simulated failure states showed loaded still posters with no 3D canvas. Enable 3D successfully recreated the interactive canvas. No browser errors were recorded in the final normal-site run; the upstream THREE.Clock deprecation warning remains.

Limits

This is an illustrated console, not a mechanically verified Game Boy circuit layout. No award or photorealism claim is made. Hardware-device testing, touch-device testing, field Core Web Vitals, GPU execution timing and OS-level reduced-motion emulation were not completed. The reduced-motion branch and unavailable-3D fallback were exercised through development controls. The browser reports an upstream THREE.Clock deprecation warning. This pass is local and has not been deployed.
