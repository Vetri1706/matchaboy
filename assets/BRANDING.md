# Matchaboy sprout identity

The sprout mascot is a scalable rendition of the logo supplied by the maintainer on 14 September 2026. The dark outline and sage leaves adapt to light and dark surfaces. The app icon uses the cream mark on a sage rounded square.

`matchaboy.ico` includes 16, 32, 48, 64, 128 and 256 pixel sizes. `matchaboy.icns` contains 128, 256 and 512 pixel representations. `matchaboy.svg` is the app icon; `matchaboy-mark.svg` is the standalone mascot. Native headers use the shared pixel grid in `include/matchaboy_logo.hpp`.

Linux draws the same mark in the library, player and Inspector header and supplies an EWMH window icon for the desktop task switcher. All three operating systems package the sprout assets; no new runtime dependency is introduced.

The maintainer supplied this design for use in the website and application. No third-party logo source or independent ownership claim is implied by this conversion.
