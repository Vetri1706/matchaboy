# Repository contents and verification evidence

This repository contains the Matchaboy emulator and its Matcha platform
extensions. The earlier, unrelated Raft project is outside this repository.

The complete native source, headers, tests, verification/download tools,
Python wrapper, and documentation are committed. The 57 implementation and
tool files in the final benchmark's frozen inventory are unchanged by
repository packaging.

Selected `artifacts/` files are intentionally tracked despite the directory's
default ignore rule. These include the final correctness reports, original
test verdict logs, independent audits, benchmark baseline and comparisons,
UDP transfer reports and frame hashes, dashboard captures, and compact frozen
source archives. Historical summaries linked by the documentation are also
retained where practical. `REPOSITORY_EVIDENCE.json` lists the tracked evidence
files, their sizes and SHA-256 hashes.

Build executables, Python environments, downloaded ROM/source/reference
collections, bulk instruction traces, full framebuffer movies, PCM streams,
and large experimental runs remain local. The preserved reports identify
these original products and their hashes where recorded; their presence in
a report does not mean that every raw product is committed to Git. In
particular, historical links to excluded executables or raw traces may only
resolve in the original development workspace. The verification tools can
produce a new complete campaign locally.

Reports retain the exact original command paths and timestamps as historical
provenance. Those paths are not runtime dependencies. No report was rewritten
to imply that an old test was executed from a fresh clone. Frozen source
archives contain relative paths and can be used to inspect the tested source.

Fetch the original external oracles with the included tools before running
their verification suites:

```sh
python3 tools/fetch_roms.py
python3 tools/fetch_ppu_tests.py
python3 tools/fetch_mooneye.py
python3 tools/fetch_mealybug.py
```

The link verification tool synthesizes its own authored test ROM. The
four-channel audio demonstration is generated by `tools/make_audio_demo.py`.
Commercial game ROMs are not included or claimed as verified.

For the current results, limitations, and exact higher-spec-host comparison
procedure, read [PLATFORM_VERIFICATION.md](PLATFORM_VERIFICATION.md).
